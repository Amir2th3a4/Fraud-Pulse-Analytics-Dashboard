Overview
Fraud Pulse Analytics is an interactive Advanced Excel dashboard designed to analyze financial fraud patterns and customer risk. The dashboard transforms raw banking data into meaningful insights using dynamic visualizations, KPI metrics, and interactive filters to support data-driven decision-making.

Key Features
- Interactive KPI Cards
- Fraud Rate Analysis
- High-Risk Customer Identification
- Credit Score Distribution
- Debt vs Income Analysis
- Credit Utilization Analysis
- Fraud by Occupation
- Age Group vs Fraud Analysis
- Dynamic Slicers and Filters
- Real-time Dashboard Navigation

Business Objective
The objective of this dashboard is to identify fraud trends, monitor customer risk, analyze financial behavior, and provide actionable insights that support fraud detection and business decision-making.
